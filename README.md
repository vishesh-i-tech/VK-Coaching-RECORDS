# ClassDesk - Coaching Management Platform

A modern, responsive landing page and web application for coaching institutes, tuition classes, and academies to replace paper registers with one simple dashboard.

## 🚀 Features
- **Daily Attendance Roster**: One-tap attendance marking with instant WhatsApp alerts.
- **Pending Fee Management**: Automatic fee receipt generation and WhatsApp dues reminders.
- **Test Marks & Progress**: Real-time batch averages and performance tracking.
- **Fully Responsive & Accessible**: Works seamlessly on mobile phones and desktops.

## 🛠️ Tech Stack
- HTML5 (Semantic & Accessible)
- Modern CSS (Custom Design System, Flexbox, Grid)
- Vanilla JavaScript (Interactive Simulators & Dynamic Configuration)

## 🌐 Live Deployment
Hosted on Vercel.
